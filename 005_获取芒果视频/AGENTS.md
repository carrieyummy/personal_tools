# 芒果视频工具目录规则

## 适用范围

- 本文件仅适用于 `D:\VSCode\personal_tools\005_获取芒果视频` 及其子目录，不规定父目录或其他工具目录的组织方式。
- 本目录未覆盖的通用约定继续继承上级规则；子目录有明确规则时，以子目录规则为准。

## 编码规则

- 项目目录层级要清晰、规范
- 共用通用的接口、文件，避免重复编码
- 以最新设计为准，不兜底、不硬编码，配置写在配置文件里，配置文件格式yaml优先。
- 用户会手动调整配置文件，测试代码、文档内容不能写死为特定值，必须以配置文件为准
- .gitignore 里要按类型放、加注释
- 禁止使用带空格的路径

## 项目结构

本项目正在开发中 实际文件夹可能有变化，以实际需求为准，同步更新此处的项目结构

- 当前目录作为芒果视频工具的根目录，内部按功能和职责分层。
- 根目录的代码文件仅保留可直接运行的入口脚本，批量下载入口为 `download_mgtv.py`；命令行参数定义、默认值、互斥关系和参数校验集中在入口脚本中，入口负责定义命令行参数、调用业务模块并处理退出码。
- 具体业务逻辑、公共接口和工具函数放入 `local/`，按职责拆分模块并通过模块导入复用。
- 正式流程读取客户端保存的登录态，经原生 HTTP 接口解析链接与正片目录，按接口由高到低的画质组逐集选档，不读取播放日志、不操作客户端界面、不要求逐集点击。`local/client.py` 提供正式与研究共用的认证和原生请求；`tasks.py` 负责清单及选集；`hls.py` 负责完整清单与断点分片；`media.py` 负责无损封装与全片解码；`storage.py` 负责指纹、锁与发布事务；`activity.py`、`application.py` 负责报告与有界调度。
- 支持 ENDLIST 点播 TS/fMP4、字节范围和主清单独立音轨；加密 HLS 尚未验证授权还原机制，遇到时明确报错。选定源未返回有效调度地址、下载或验证失败时不改用低档或 SDR 备用源。营销 HDR 描述与实际媒体属性分别记录，不把 SDR 增强当作 HDR。
- 测试脚本统一放入当前目录的 `tests/`。
- 主配置放在 `configs/config.yaml`，专项配置同样放在 `configs/`；代码、测试和文档均以实际配置为准，不重复硬编码配置值。
- `configs/native_playback.yaml` 独立维护协议版本、能力协商与状态约束，不在代码中写死特定清晰度或画质名称。能力声明用于请求原码流，不等于本机显示器或硬件已通过对应格式验证。
- 本机芒果视频客户端安装目录、下载目录及经验证的缓存处理参数集中在 `configs/` 下对应的专项配置中；若确认需要调用客户端 DLL，再配置 DLL 文件名、版本选择和接口位置，不预设必须依赖 DLL。
- 研究资料和第三方参考资源放在 `research/`，与业务模块分开管理。
- 播放接口研究入口为 `research/playback_probe.py`，参数与本机路径读取 `configs/playback_research.yaml`；支持结构检查、原生接口探测、选集查询、静态接口定位及隔离的播放器能力查询，不操作客户端界面。
- 32 位播放器能力查询辅助脚本位于 `research/query_player_caps.ps1`；调用前校验已验证 DLL 的 SHA256，辅助进程不接收登录票据。
- 实网验收入口为 `tests/verify_playback_api.py`，按专项配置逐集验证目标画质、完整 HLS 清单和抽样分片解码；脱敏报告及媒体样本写入已忽略的 `research/results/`，不保存登录票据或带签名媒体地址。
- `tests/accept_download.py` 是显式单集全片验收入口，按当前主配置和清单选项执行下载、完整解码、发布及第二次指纹复用。普通 `unittest` 发现测试只使用临时目录、回环 HTTP 与合成媒体，不访问真实账号。
- `tests/benchmark_media.py` 读取已登记且指纹一致的成品，以相同样本和固定后端分配比较串行/并发完整解码。报告注明是否包含下载与发布，不将解码阶段比值当作端到端下载加速。所有研究及验收产物写入调用方指定的已忽略目录。

## 下载约定与用法

- 以下命令以工具目录为当前目录，解释器以当前工作区 `settings.python.defaultInterpreterPath` 为准。PowerShell 示例：`& "C:/ProgramData/miniconda3/envs/test_regression_py3.12/python.exe" "download_mgtv.py" --url "download_list/download_list.yaml"` 批量读取清单；`--url` 可重复混合清单与官方视频链接。不传 `--url` 时交互输入，不自动读取默认清单。
- `--login-only` 仅检查客户端已有登录态；`--list-formats --url "官方链接" --no-all-parts` 只查看链接集档位；`--all-parts`/`--no-all-parts` 显式覆盖整剧范围。未传 CLI 范围时按任务项、清单全局、主配置顺序继承。`quality` 为每集独立排名，档位不存在时报失败；`date`/`commit`/`title` 为备注，不用于生成媒体目录。暂不支持拼接。
- 输出根目录与爱奇艺项目仅初始值一致，各自配置独立维护。剧目录使用源站标题及 `_mgtv` 剧集编号；文件包含集序、源站标题、实际清晰度与视频编号。已有成品必须匹配源/清单身份并通过完整 SHA256 才复用；源变化另建版本，同名未知文件不覆盖。
- 共享根目录专用文件由主配置 `logging` 定义，强制保留 `mgtv_` 或 `.mgtv_` 前缀，避免与爱奇艺索引、日志、锁混用。分片现场按视频及源指纹隔离；失败或取消保留，成功清理由配置决定。持续变化的清单达到重试上限后停止该集。
- FFmpeg 使用配置指定的可执行文件，当前适配包含 FFmpeg 9 的本地 HLS 扩展校验参数。至少启用 CPU/CUDA 一种完整验证后端；启用 CUDA 时先检查初始化，具体格式仍逐集验证，失败不切换设备。CPU 与 GPU 各有独占槽，每集使用其中一个后端完整解码全部视频和预期音轨，禁止缩放、转码及色调映射。
- 日志提供只监听 `127.0.0.1` 的实时页面、历史 JSON 与带时间戳的离线 HTML。单集失败继续其他集；登录失效停止新请求。Ctrl+C 回收进程并保留断点，返回 130；参数错误返回 2，其他失败返回 1。
- 依赖安装（PowerShell）：`& "C:/ProgramData/miniconda3/envs/test_regression_py3.12/python.exe" -m pip --proxy "" install -r "requirements.txt"`；`PyYAML` 为正式依赖，`capstone` 只用于既有二进制研究。FFmpeg 路径由主配置提供，不在代码中搜索其他程序兜底。
