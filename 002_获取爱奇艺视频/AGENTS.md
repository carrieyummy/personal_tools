# 爱奇艺视频工具目录规则

## 适用范围

- 本文件仅适用于 `D:\VSCode\personal_tools\002_获取爱奇艺视频` 及其子目录，不规定父目录或其他工具目录的组织方式。
- 本目录未覆盖的通用约定继续继承上级规则；子目录有明确规则时，以子目录规则为准。

## 编码规则

- 项目目录层级要清晰、规范
- 共用通用的接口、文件，避免重复编码
- 以最新设计为准，不兜底、不硬编码，配置写在配置文件里，配置文件格式yaml优先。
- 用户会手动调整配置文件，测试代码、文档内容不能写死为特定值，必须以配置文件为准
- .gitignore 里要按类型放、加注释
- 禁止使用带空格的路径

## 项目结构

- 当前目录作为爱奇艺视频工具的根目录，内部按功能和职责分层。
- 根目录的代码文件仅保留可直接运行的入口脚本，当前入口为 `decode_qsv.py` 和 `download_iqiyi.py`；命令行参数定义、默认值、互斥关系和参数校验集中在入口脚本中，入口负责定义命令行参数、调用业务模块并处理退出码。
- 具体业务逻辑、公共接口和工具函数放入 `qsv_local/`，按职责拆分模块并通过模块导入复用。
- 链接下载模块放在 `qsv_local/playback/`。客户端只需登录后打开任意正片并暂停一次；后续任意电视剧、任意集均通过独立播放 SDK 请求，不启动或切换当前播放界面，不创建客户端离线下载列表任务。
- 测试脚本统一放入当前目录的 `tests/`。
- 主配置放在 `configs/config.yaml`，专项配置同样放在 `configs/`；代码、测试和文档均以实际配置为准，不重复硬编码配置值。
- 成品目录由 `naming.series_template` 和客户端下载记录的专辑名、`AlbumID` 生成；视频文件由 `naming.episode_template`、`vedioorder` 集序和源文件名生成。专辑 ID 或集序缺失、无效时停止映射；命名元数据发生变化时跳过该任务。旧镜像目录的成品和索引保持原位，不自动迁移。
- 链接下载在新成品的电视剧目录前追加 `naming.playback_date_prefix`；日期仅取官方专辑 `publishTime`，展示时区偏移读取专项配置，按批次缓存并固定。该前缀不影响视频文件名、本地 QSV 转换或已运行的旧批次；旧链接成品校验通过后原位复用，不自动迁移。新增功能不得重启、停止或重新映射用户正在下载的任务。
- 研究资料和第三方参考资源放在 `research/`，与业务模块分开管理。

## 工作区配置

- 本工具使用父目录中的 `002_获取爱奇艺视频.code-workspace`；该文件不属于本文件的目录管辖范围，本文件不规定其他工具的工作区配置。
- 涉及本工具工作区配置的任务中，Python 解释器路径统一配置在 `settings.python.defaultInterpreterPath`，启动、任务等其他配置通过 `${config:python.defaultInterpreterPath}` 引用，不重复硬编码解释器路径。
