# 爱奇艺视频工具目录规则

## 适用范围

- 本文件仅适用于 `D:\VSCode\personal_tools\002_获取爱奇艺视频` 及其子目录，不规定其他工具目录的组织方式。
- 本目录未覆盖的通用约定继续继承上级规则；子目录有明确规则时，以子目录规则为准。

## 编码规则

- 项目目录层级清晰，复用公共接口和文件，避免重复编码。
- 以最新设计为准，不兜底、不硬编码；配置优先使用 YAML，代码、测试和文档均以实际配置为准。
- `.gitignore` 按类型分组并添加注释；禁止使用带空格的路径。

## 项目结构

- 当前目录为爱奇艺视频工具根目录，结构随实际实现同步维护。
- 根目录仅保留可运行入口；`download_iqiyi.py` 和 `decode_qsv.py` 统一定义和校验各自参数、调用业务模块并处理退出码。
- 业务和公共模块放在 `qsv_local/`，链接下载模块放在 `qsv_local/playback/`；清单放在 `download_list/`，正式配置放在 `configs/`，测试放在 `tests/`，研究资料和配置放在 `research/`。
- 视频解析、下载及 QSV 转换以爱奇艺实际格式和接口的验证结果为准。

## 文档维护

- 修改功能时，同步更新 [流程设计文档](docs/设计与流程.md) 中受影响的设计、流程和关键行为，使文档与实际实现一致。
- README 仅保留简洁的使用方法，包括运行所需的准备、配置和命令。功能变更影响使用方法时，同步更新相关说明。流程设计和实现细节统一记录在流程设计文档中。

## 工作区配置

- 使用父目录的 `002_获取爱奇艺视频.code-workspace`，入口、参数或测试配置变化时同步维护。
- Python 解释器仅在 `settings.python.defaultInterpreterPath` 配置，其他位置通过 `${config:python.defaultInterpreterPath}` 引用。

## 并发配置约定

- 继承仓库根目录 `AGENTS.md` 的统一规则：`download.threads` 仅控制媒体下载；解析、选档、复用检查、续签及后处理共用顶层 `max_in_flight` 总并发上限。等待队列和设备独占槽按各自配置限制，不计为活动下载；本地转换使用处理上限。
