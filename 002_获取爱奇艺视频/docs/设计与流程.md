# 爱奇艺视频设计与流程

本文件记录模块职责、处理流程和关键约束；具体参数以实际 YAML 及注释为准。日常操作见 [README](../README.md)，原有详细说明和命令见 [操作与验证参考](操作与验证参考.md)。

## 目录与职责

- `download_iqiyi.py`：链接清单下载入口，负责配置、清单下标和集序等命令行参数。
- `decode_qsv.py`：本地 QSV 转换入口，读取必填主配置。
- `qsv_local/playback/`：链接解析、公开正片目录、原生播放会话、选档、媒体下载、调度、日志和发布。
- `qsv_local/`：配置校验、客户端下载状态保护、QSV 解析、本机 SDK、封装、解码验证、索引、存储和公共流水线。
- `configs/` 保存正式配置，`download_list/` 保存链接清单，`tests/` 保存测试与验收入口；研究资料及专用配置放在 `research/`，研究流程直接引用所需正式配置。

## 链接下载流程

1. 读取播放专项配置、主配置和清单，固定本次链接快照。客户端登录后打开任意正片并暂停一次，后续由独立播放 SDK 请求各剧各集，不切换可见播放页，也不创建客户端离线下载任务。
2. 按清单逐项解析链接并完整校验公开正片目录的分页、范围和集序，每项校验完成后交接下载，同时继续发现后续目录。只处理有效正片；`--plan` 仅输出公开目录和计划，不请求播放会话或获取媒体。
3. 按专项配置排序原生画质候选，当前正式流程仅适配最高声明画质组；音质依据主配置和原生音轨声明独立排名。检查账号授权、视频身份、清单和正片时长，不把试看、其他画质或播放器滤镜当作目标来源。
4. 核对同源成品的发布证明、预期文件名及实际字节数，匹配即复用，摘要和媒体属性沿用发布记录。需要下载时按清单实际内容解析 HLS 或 DASH，并处理独立音轨。分段按长度和 SHA-256 保存断点，重新运行时核对稳定来源、范围和内容；来源变化使用独立现场。
5. 下载完成后释放下载名额并交接处理：SDK 授权处理、音轨重建、无损封装、全片解码、媒体属性及完整性检查。启用的 CPU/GPU 各有独占解码槽，失败不自动切换设备。
6. 验证和摘要通过后保留已验证候选，在输出锁下复制校验、发布并原子提交每剧 `video_info.json`；索引提交失败回收本次新副本并保留候选。按配置清理成功任务的中间媒体，失败或取消保留现场。

## 本地 QSV 转换流程

1. 根据主配置扫描输入目录，只处理客户端数据库明确登记完成且没有下载临时标记的 QSV；数据库以只读方式访问，不改写源文件或客户端记录。
2. 使用下载记录的专辑名、专辑 ID 和集序映射输出；缺失、无效或命名元数据变化时停止或跳过相应任务。检查来源及已登记成品，符合条件时复用。
3. 对当前已验证的 QSV 格式执行提取和本机 SDK 处理，再无损封装、完整解码并检查帧数、源文件与成品摘要，验证通过后发布并更新索引。旧镜像目录的成品和索引保持原位，不自动迁移。

## 并发、命名与恢复

- 链接模式的 `download.threads` 限制同时传输媒体的剧集数；单集分片并发独立读取播放专项配置。目录发现、解析、复用检查和后处理共用顶层 `max_in_flight` 处理池，本地转换也使用该上限。
- `download.queue_capacity_gb` 按实际字节限制已下载且等待后处理的媒体，空队列允许单集超限；容量不包含下载中、等待入队、处理中及历史失败现场。队列背压时暂停新下载，下载完成即释放下载名额。处理池和设备、封装、授权及发布等内部资源槽共同约束实际并发。
- 链接新成品的剧集目录按 `naming.playback_date_prefix` 添加官方专辑 `publishTime` 的上映日期；展示偏移读取专项配置，专辑编号及日期必须有效。同一批次固定命名和日期；已登记旧链接成品校验通过后原位复用，不自动迁移。本地 QSV 使用原有命名模板。
- 输出锁保护索引和发布；同平台冲突不覆盖成品。链接流程已验证候选在发布受阻时保留，重新运行时校验后可续发。批次开始后修改 YAML 不改变正在运行的批次，更新功能不停止或重启已有任务。
- 链接实时页面可取消待解析链接或整剧未完成任务；取消是协作式的，已完成成品和可靠断点保留。终端 Ctrl+C 中断时也保留现场。实时记录和离线报告使用配置指定的独立文件。
- 当前批次的失败集可从实时网页清除断点并重试。网页只提交当前剧集行的标识，调度器重新排队并更新该行和批次计数。清理在共享处理池和来源锁内执行，仅处理本集已登记的工作目录。重试重新选档和校验清单，成品目录及索引仍按正常发布规则处理。
- 链接下载队列和后处理都结束后，网页服务继续运行，调度器等待重试或停止请求。只有当前空闲批次接受“停止服务”，与重试请求在同一日志锁内协调。正常停止后写入最终日志、导出离线报告并关闭服务。

## 格式与验证边界

链接路线以已验证客户端的 TS AVC/HEVC、DASH SegmentList AV1/CENC 和独立 AMP4 音轨适配为准；其他格式、音轨和客户端 ABI 需先独立验证。QSV 转换以已验证的容器、授权版本和本机 SDK 为准；客户端升级后接口不兼容时重新分析，不能只更新摘要。票据及临时媒体地址只在内存中使用，不写入报告。

普通单元测试使用隔离输入和替身，不代表真实客户端授权或设备解码已经验收。实网、格式研究和设备验收入口及原有可执行命令见 [操作与验证参考](操作与验证参考.md) 和 `research/`。
