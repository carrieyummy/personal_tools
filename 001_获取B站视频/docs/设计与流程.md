# B 站视频下载流程设计

本文记录现有流程和边界，运行参数以 [config/config.yaml](../config/config.yaml) 及其注释为准。日常操作见 [README](../README.md)，详细命令、配置及行为见 [操作与命令参考](操作与命令参考.md)。

## 入口与模块

- `download_bilibili.py` 集中定义和校验下载、登录检查、画质查询、离线拼接及信息补全参数，并调用业务入口。
- `bilibili_downloader/application.py` 和 `workflow.py` 协调运行模式及任务；`manifest.py` 解析清单；`discovery.py` 按完整画质确认组增量发现；`scheduler.py` 协调下载池、共享处理池和有界队列。
- `api.py`、`bangumi.py`、`identity.py` 和 `auth.py` 负责原站接口、番剧、来源标识及登录会话；`quality.py`、`variants.py` 负责画质和格式选择。
- `downloader.py`、`media.py`、`subtitles.py` 和 `merge.py` 负责传输、封装、字幕及拼接；`source_records.py`、`merged_records.py`、`provenance.py` 和 `storage.py` 负责来源、指纹、索引和事务。
- `activity_log.py`、`log_server.py` 及页面模板负责运行记录、实时网页和离线快照；`runtime.py` 管理取消和活动网络、媒体进程。

## 下载流程

1. 入口读取配置及命令行参数，解析链接、BV/AV、番剧 ep/ss 或 YAML 清单。清单任务可覆盖全局下载范围、拼接及画质设置；普通链接由用户交互选择画质。主线程处理登录和画质确认，工作线程使用独立 HTTP 会话和认证快照。
2. 按完整确认组发现投稿和番剧目录，查询目标分 P 的可用画质并确定选择；一组完成确认后即可交接下载，后续组继续在共享处理池发现。普通关联季按原站季列表展开，同一番剧确认一次逐集档位排名，单季或普通投稿选择画质上限。
3. 根据画质及拼接优先策略规划实际来源版本，检查来源身份、格式和已登记成品。符合条件的结果复用并跳过传输；需要下载的分 P 进入下载池，单个分 P 内顺序传输音视频流。
4. 原始流下载完成后释放下载名额，并按实际字节容量排队；封装、指纹、快速媒体探测、字幕和发布使用共享处理池。保留原始编码，字幕独立保存；当前流程不执行 CPU/GPU 全片解码验证。
5. 每个投稿所需分 P 结算后进入同一处理池收尾；拼接组在投稿内顺序执行，其他投稿可继续下载。来源、画质、音视频编码和分辨率必须兼容，不自动转码。结果及来源记录写入索引，实时网页和离线快照展示状态。

## 番剧、画质和拼接

- 开启 `download.all_seasons` 时，番剧按关联季列表去重展开，每季处理正片，季内预告和花絮不混入正片；普通 BV/AV 不受影响。关联季普通链接选择逐集档位排名，档位不足的集单独失败，不自动降档。
- 清单按任务目标分 P 的档位并集决定画质上限，各项和全局设置以实际清单为准。拼接优先策略可在允许范围内为不同组选择兼容版本；相同分 P 可因画质或编码不同保留多个版本，相同来源版本只传输一次。
- `--merge-parts` 支持不拼接、全部拼接或分组范围；离线 `--merge-video` 使用已有投稿或番剧季文件，无需登录。合并前核对所选来源和兼容性，覆盖与复用遵循 `merge.overwrite_existing` 及来源快照；生成或提交失败时保留或恢复旧成品。

## 并发、断点和取消

- `download.threads` 只限制活动媒体下载的分 P 数；目录发现、选档、复用检查、封装、字幕、发布和拼接收尾共用 `max_in_flight` 处理上限。下载和后处理可重叠，等待或复用检查不占下载名额。
- `download.queue_capacity_gb` 按实际原始流字节限制下载完成且等待后处理的容量；空队列允许一个超限分 P 独占。下载中、等待入队、处理中和历史失败现场不包含在容量内，队列背压时暂停新下载。
- 断点按来源身份、分 P、CID、画质和格式版本隔离；番剧额外核对 EP。重试及重新运行时检查现有来源和文件，不把临时流当作已完成成品。
- Ctrl+C 停止新任务派发，回收网络读取和媒体进程，保留可靠断点、原始流及已完成成品；已启动的旧批次不自动停止或重启。任务失败按结果报告，其他可处理任务继续。

## 记录与验证边界

普通投稿、番剧季和独立附加内容使用各自来源标识归档；源索引和合并索引记录格式版本及来源快照。日志服务只监听本机回环地址，结束后保存 JSON 与离线 HTML；日志和输出目录由配置决定。

`tests/` 使用模拟原站、本地 HTTP/HTTPS 和合成媒体验证流程；相关测试及命令见 [操作与命令参考](操作与命令参考.md)。真实登录、会员权限及原站可用画质以运行时结果为准。
